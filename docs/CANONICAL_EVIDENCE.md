## 2. Dataset Provenance Taxonomy

Every dataset used within the platform is classified under one of five mutually exclusive scientific provenance classes:

```
┌─────────────────────────┬────────────────────────────────────────────────────────────────────────────┐
│ Provenance Class        │ Definition & Real-World Generalizability Standard                          │
├─────────────────────────┼────────────────────────────────────────────────────────────────────────────┤
│ REAL_EXTERNAL_DATA      │ Real-world historical financial/blockchain records (e.g. IEEE-CIS,         │
│                         │ European Credit Card, Elliptic). Bank federation is simulated.             │
│ EXTERNALLY_SIMULATED    │ External, peer-reviewed multi-agent behavioral simulations (e.g. PaySim,   │
│                         │ IBM AMLSim). Reflects calibrated agent rules, not bank customer PII.       │
│ PROJECT_SYNTHETIC       │ Internal synthetic datasets generated by repository code (e.g. SynthAML,   │
│                         │ AMLNet, CrossBank). Restricted to algorithm verification & stress-testing. │
│ CONTROLLED_TESTBED      │ Laboratory mathematical testbeds (e.g. DP-SGD Opacus noise sweeps,         │
│                         │ Dirichlet Non-IID skew partitions, local gateway microbenchmarks).         │
│ UNKNOWN_PROVENANCE      │ Unverified data. STRICTLY PROHIBITED from canonical evidence.              │
└─────────────────────────┴────────────────────────────────────────────────────────────────────────────┘
```

## 4. Superseded and Retired Evidence Inventory

Historical results whose numerical values remain true for the historical experiment but must **not** be presented as current canonical evidence:

1. **IEEE-CIS Synthetic Smoke Fallback (`0.7811 / 0.7554`)**:
   - *Origin*: An uncalibrated 10-feature synthetic generator used when Kaggle raw files were unmounted.
   - *Lifecycle*: Permanently superseded by Level 1 execution on the full 590,540 real Kaggle transactions ($0.4422 / 0.3895$).
2. **PaySim Synthetic Fallback (`0.4654 / 0.1463`)**:
   - *Origin*: A 10-feature synthetic fallback run.
   - *Lifecycle*: Permanently superseded by the 10% systematic sample of the physical PaySim CSV ($0.9545 / 0.9545$).
3. **Credit Card Legacy Unequal-Budget (`0.7920 / 0.7750`)**:
   - *Origin*: Compared 2 centralized epochs against 10 federated rounds.
   - *Lifecycle*: Permanently superseded by budget-equalized controlled evaluation ($0.8219 / 0.8248$).
4. **Elliptic Synthetic 1,500-Node Chain (`0.9001 / 0.9860`)**:
   - *Origin*: A toy synthetic chain graph used during initial script development.
   - *Lifecycle*: Permanently retired and isolated to `graphsage_synthetic_smoke_benchmark.json`. Replaced by canonical real-data multi-seed benchmark ($0.3761$).
5. **Byzantine 99.7% Universal Retention Claim**:
   - *Origin*: An algebraic single-seed Gaussian proxy with centroid leakage.
   - *Lifecycle*: Quarantined to `byzantine_benchmark_sign_inversion.json`. Canonical 72-condition federated evaluation on real Credit Card data shows attack- and seed-dependent performance (Trimmed Mean achieved $99.54\%$, Multi-Krum $98.48\%$, Single Krum degraded).
6. **CrossBank v1 7-Scenario Prototype (`0.9729 / 100% DR on 2 incidents`)**:
   - *Origin*: CFI-CrossBank-01 architectural prototype evaluating exactly $N=2$ synthetic test incidents in Scenario 7.
   - *Lifecycle*: Formally superseded by CFI-CrossBank-02 (Protocol 2.1.0, 5 seeds, neural benchmark, $N=133$ Scenario 7 incidents). Realistic local features achieved only $3.76\%$ recall on Scenario 7.
7. **Latency Pre-Calibration Estimates (`2.29 / 17.77 / 71.99 ms`)**:
   - *Origin*: Pre-repair measurements without concurrency warm-up.
   - *Lifecycle*: Permanently superseded by multi-repetition benchmark ($N \ge 1000$ per tier across 3 independent sweeps).

## 5. Preserved Canonical Negative Findings

Scientific integrity requires full transparency regarding negative results. The following findings are actively preserved in canonical evidence:

1. **IEEE-CIS Controlled Federation Gap**:
   - FedAvg AP ($0.3895$) incurs an $11.9\%$ relative drop compared to Centralized Pooled ($0.4422$) under Dirichlet $\alpha=0.5$ label skew. Demonstrates that client partitioning and non-IID drift degrade performance on tabular payment fraud.
2. **Elliptic Relational Modeling Negative Result**:
   - Tabular MLP (0-hop, no graph edges) achieves AP $0.5778$, significantly outperforming 2-layer Inductive GraphSAGE (AP $0.3761$) under out-of-time temporal evaluation. Graph structural aggregation introduces out-of-time negative transfer on transaction DAGs.
3. **CrossBank v2 Scenario 7 Multi-Hop Detection Failure**:
   - Realistic bank-local features detected only 5 of 133 pooled Scenario 7 test incidents ($3.76\%$ pooled recall). Centralized local features detected 0/133 ($0.0\%$). Proves that isolated and federated models using bank-local features fail to detect multi-institution layering.
4. **CrossBank v2 Bank C Zero-Positive Cold-Start Low-FPR Failure**:
   - Bank C test recall at enterprise-grade $0.1\%$ false positive rate threshold was exactly $0.0\%$ in all 5 seeds. Parameter sharing provides ranking discrimination but fails to establish actionable decision boundaries for zero-positive institutions.
5. **CrossBank v2 Institution-Level Regressions**:
   - Federated ROC was lower than isolated local training for Bank A in 5/5 seeds ($-0.0293$) and Bank B in 4/5 seeds ($-0.0171$). Pooled federated advantage is driven entirely by rescuing Bank C ($+0.3514$ dROC).
6. **Differential Privacy Utility Degradation**:
   - At stringent privacy budgets ($\epsilon = 0.35$, $\sigma = 3.0$), neural classification collapses from PR-AUC $0.8965$ to $0.3465$.
